# 模型作为产品组件交付

本产品已通过本地接口集成 Qwen3.5 9B，模型不属于需要候选人自行训练的自研权重。模型进程与 Web 服务分离，启动入口统一；离线运行不需要云端 API Key。

## 提交包与模型组件

本次题目附件限 30MB，而已测试的本机模型组件约 6.6GB，不能合并后直接上传。产品源码、启动脚本、模型版本锁、许可证和测试记录放在小附件中；模型由用户首次下载，或通过另行提供的大文件渠道交付离线组件。不要承诺把权重压缩进 30MB。

在线准备：先安装 [Ollama](https://ollama.com/download) 和 Node.js 24，执行项目 `npm ci`，再双击根目录 `准备本地模型.cmd`。该操作需网络及数GB下载空间；模型准备好后双击 `启动本地AI.cmd`。标签可能更新，版本以 `model-lock.json` 所记录摘要为复现实验依据，新版本应重新验收。

离线准备：在拥有本轮已测试模型的电脑运行 `node scripts/export-local-model.mjs`，只检查版本和组件清单；明确需要复制时运行 `node scripts/export-local-model.mjs --export`。结果位于被 Git 忽略的 `outputs/offline-model`，仅包含指定 manifest、内容寻址 blobs、许可证与版本锁，不含 Ollama 账号、SSH 或 API 配置。实际导出逐个检查 SHA-256，不覆盖非空目录。

接收方需兼容的 Ollama 运行时。导出目录的 `ollama-models` 是模型缓存布局，可作为专用 `OLLAMA_MODELS` 目录运行 Ollama；使用专用目录时应先退出已有 Ollama 服务，再由用户在终端为新服务设置该环境变量并启动，避免两个服务争用端口。未把该离线组件描述为免安装的单文件 exe。

本轮已经实际导出约6.55GB组件，逐个核对8个组件的大小和SHA-256，并用指向导出目录的独立Ollama服务验证模型识别、模型架构和Q4_K_M格式。未在第二台新电脑进行运行时安装和完整推理验收；首次交付不同硬件时仍需检查。

## 许可证及模型效果

模型附带 Apache-2.0，完整文本见 `QWEN-LICENSE.txt`，含 Alibaba Cloud 原始归属；再分发应保留许可证及适用的归属/NOTICE，不将其说成自研模型或修改后的权重。当前只调整证据组织、提示词和推理配置，未训练或修改模型权重。

模型卡与导入方式：[Qwen3.5 9B](https://ollama.com/library/qwen3.5:9b)、[Ollama 模型导入](https://docs.ollama.com/import)。9B 模型的优势是可本地运行；本产品的真实问题集和保留题结果才是领域适用性的依据，不将通用模型宣传分数当作财报语义验收。
