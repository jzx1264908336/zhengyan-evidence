# 数据来源、计算与边界

## 快照

基础财报版本 `filings-20261104-v1`，应用当前组合版本 `research-20261104-v2`，获取与研究截止日期 2026-11-04。披露日期按原始公告日期记录；不捏造日内发布时间。不提供历史时点回测，源报表可比值可能包含历史调整。

基础的 6 份来源：贵州茅台 2024 年报、2025 年报、2026 三季报；泸州老窖 2025 年报；山西汾酒 2025 年报；五粮液 2025 年报摘要。每份来源 URL、哈希、页数、日期在 snapshot.json 的 sources 中完整列出。

## 原始值

Observation 包括 id、label、raw、unit、period、sourceId、page、scope。raw 保留报告精度和千位分隔。金额内部先转换为 BigInt 分，再转为计算数值；当前金额范围在整数安全精度内，展示层才舍入亿元。百分数原值在读取时除以 100，不再次放大。原值为零与缺失严格区分。

年度流量为全年；9M 为 1—9 月累计；Q 为明确披露单季。资产/权益为时点存量，不能累计相减生成单季。归母净利润与合并净利润分开，现金流比值使用合并净利润。

## 公式

| 项目 | 口径 |
|---|---|
| 正基数同比 | 本期/上年同期−1；基期≤0 不返回普通增长率 |
| 单季流量函数 | 本累计−上一累计；禁止存量这样计算 |
| TTM | 上年度全年+本期累计−上年同期累计；缺项则不可算 |
| 营业收入毛利率 | （营业收入−匹配营业成本）/营业收入 |
| 现金流比值 | 合并经营现金流/合并净利润，含少数股东损益 |
| 同行中位数 | 排除缺失与用户排除样本；有效同行少于 3 家不计算 |
| 最大回撤函数 | min(价格/截至当日峰值−1)，仅独立测试，产品未接入行情 |

同比和比率输出为内部比率，界面显示百分比或倍数。TTM 不是全年预测。模型不能自行推算数值。

## 同行

泸州老窖、山西汾酒、五粮液依白酒主营和公开材料可得性选入；并非完整行业样本。业务结构、香型、价格带不同，贵州茅台还合并财务公司。五粮液 2025 年报摘要第 3 页披露部分收入确认核算调整，默认不纳入同比中位数；用户可改变样本，但不能消除可比性风险。

## 质量与缺失

原始 API 未接入，所以不生成 API 请求 ID。财报 sourceId + 页码 + 原字段 ID 是当前追溯链。V1 尚无市场数据；V2 纳入腾讯公开快照，估值可计算，但合理性及因果关系仍未知。利润现金比值不代表主业比值，财务公司影响不以简单现金流差额机械剥离。

来源哈希仅验证下载文件身份。原始披露、数据解释或会计估计可能存在错误，不能因来源权威就消除不确定性。


## V2 行情与估值

个股和沪深300各244个日线样本，2025-11-03至2026-11-04。个股使用 `qfqday` 供应商前复权价格，指数使用 `day` 点位。对齐共同日期，展示排除数量，不补值。数据不宣称为分红再投资总回报，未使用完整公司行动序列独立重建复权因子。

报价按字段3记录不复权价格、字段45记录总市值（原始单位亿元，转为元）。不使用含义未独立核验的供应商PE字段。主标的市值用2026-09-30股本×快照收盘价交叉检查精度；这不自动证明股本在两时点间没有任何变化。

PE TTM=同日供应商总市值/确定性TTM归母净利润；PB=同日总市值/最近报告期归母权益；同行一律比较2025年度静态PE，不混用TTM。PB的报告期滞后在公式内明确显示。

## V2 修订

五粮液2025三季报原始版发表于2025-10-31、更新后发表于2026-04-30，两份PDF第1页的同一累计期收入、归母利润、经营现金流分别归档。`supersedes`保留替代关系，归母净利润/收入随输入版本重新计算。旧计算仍保留用于对照，不覆盖原文。

来源页码对PDF有效；行情为字段/日期定位，page=0，不拼接虚假的PDF页码。市场哈希是归档UTF-8响应哈希，不等同于原网络编码字节的哈希。
