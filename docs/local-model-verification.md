## 已观察并修正的问题

1. 初版照抄阿拉伯数字，校验器拒绝。改为定性生成与程序附加数值；结构生成使用 JSON Schema，原有数字检查保持启用。
2. 复杂正则约束下出现重复字段直至截断；改为简单字符约束与精简证据包，截断输出继续拒绝。
3. 合并/归母口径回答和无关概括不够准确；补充明确口径说明、按问题排序的证据以及输出覆盖要求。
4. 模型将基准名称写成“沪深三十指数”；该回答被拒绝。输入统一使用“基准指数”，准确名称和数据在程序核验区展示。
5. 中文小数比值可能绕过阿拉伯数字检查。仅允许按两位显示精度唯一匹配已引用指标的中文比值转换为指标占位符；不匹配、无引用或歧义均拒绝。其他中文数值生成风险仍不等于已被穷尽处理。
6. Cloudflare 本地预览读取旧 `.env` 导致接口混用；由本地模式固定选择本地配置，忽略旧云端模型名、接口与密钥。
7. Cloudflare Workers 不接受 Fetch `redirect:error`。改为 `manual`，返回重定向即失败，不跟随 Location。该修复也适用于云端适配。

## 逐条语义复核结论

本次由 AI 辅助逐条检查真实输出，候选人仍需亲自复核。未将结构通过率当作语义正确率。

- 现金流与销售回款区别、财务公司影响、未知风险、估值时点滞后、同行收入确认限制、提示注入和交易边界已具备可演示结果。
- 第 5 题虽不再给出错误数字，但主要解释合并比值与财务公司影响，未充分直接回答归母与合并归属范围的区别。
- 第 7 题用“数据异常”概括收入确认调整，措辞偏重；应回到原文，不应把核算调整自动认定为公司异常。
- 第 19 题覆盖了经营与估值，却未充分解释行情维度；多维问题完整性仍需改进。
- 个别论断引用了存在且属于任务的指标，但其具体因果或口径解释更应同时引用相应 note；当前校验不能证明每个引用均直接支撑整句话。

因此本版是**可运行、可复核的本地 AI 主链路**，不是已完成全部语义质量验收的最终答卷。面向评审演示时应保留上述限制，优先展示已经逐条核验的现金流问题及引用钻取。

## 启动与部署边界

已安装依赖的本机运行 `npm run dev:local-model`，或 Windows 双击根目录 `启动本地AI.cmd`；访问 `http://127.0.0.1:5173/`，保持终端运行。`npm run test:model:local` 可重复真实问题集，不消耗云端 API 额度；本地推理会占用计算资源。

本轮没有把本机模型暴露到公网，也没有将本地地址部署成在线 AI 服务。原公开站点仍为 V2 财报核验版，不能直接连接开发者或评审电脑上的 Ollama。公开在线 AI 仍需要独立模型服务。
