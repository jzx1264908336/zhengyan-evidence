## 建议演示路径

1. 在诊断总览提交“现金流增长是否说明酒卖得更好了？”，阅读真实 AI 与合并口径限制，点击指标或披露证据。
2. 提交“请分别分析贵州茅台的估值和行情。”，核对两节回答及分别关联的证据。
3. 提交“请分析贵州茅台最近60个交易日走势。”，核对 60 个共同交易日指标；再在行情工作区切换窗口和查看计算依赖。
4. 在同行比较查看五粮液收入确认调整，在更正与版本查看原始版、更新版及依赖重算，切换披露日期以检查信息可见性。
5. 提交“请分析工商银行的经营质量。”或“请分析贵州茅台2024年的现金流。”，核对范围/期次说明；这些问题不调用模型，不自动换成茅台最新期回答。
6. 将待核验问题保存到研究清单，刷新验证保留，再导出研究摘录。

## 数据与实现

固定截止日为 2026-11-04。共 11 项来源，包含 8 份原始财报；563 项观察由 67 项财务值、个股/指数各 244 个收盘值及 8 项报价/市值构成。每项财务观察保留来源、页序、单位、报告期和归属口径。财报与行情固定快照分别标注，不宣称实时数据或商业数据授权。

程序负责同比、TTM、现金覆盖、毛利率、估值、区间表现、最大回撤及版本依赖；规则组织事实、分析推断、未验证与正反证据；本地模型基于对应证据包逐节解释，程序附加数值及引用。模型输出经过格式、数字、引用和已知语义回归检查，最多一次校验修正；失败保留明确失败状态。

用户最终选择公开财报与本地模型方案，**未接入扶摇/iFinD**。指定数据服务是题目优先项，本作业使用可核验的公开来源替代，并如实说明。未将配置占位、模拟测试或未授权工具写成真实接口集成。

## V5 修复与验收

- 修复估值与行情组合只回答一个维度的问题；补充经营与估值组合。
- “走势”进入行情回答，20/60/244 个共同交易日证据与请求窗口一致；其他长度、自然日和早期年度专项请求明确说明不支持。
- 工商银行等已知非目标公司及非目标证券代码不再误用茅台数据。仍为有限规则路由，不声称理解任意公司和任意金融问题。
- 所需指标缺失时撤回方向性事实，暂停 AI 解读。测试使用合成缺失条件，不是实际公司数据缺失。
- 增加中文倍数、中文百分比与直接交易建议的拦截；修复真实模型出现的“两者变动幅度均受财务公司影响”错误归因。
- 纠正五粮液季度差异描述的误拦截：允许忠实转述年报披露，仍禁止据此认定造假或扩展另一更新事件的原因。
- 修正文档的历史状态冲突及多维问题的总览摘要。

本轮完整自动测试 **97/97**、TypeScript 检查及生产构建通过。测试命令：`npm test`、`npm run typecheck`、`npm run build`。

真实模型主问题集为 20 题，另有 4 个实际 HTTP 回归（两维、60 交易日、非目标公司、早期年份）。实际输出记录见 `final-model-results.json` 与 `final-http-results.json`。范围拒答不调用模型；`verified` 仅表示契约校验通过，不表示每句语义已经由机器证明。主问题为开发期回归，未经严格盲测，人工语义复核仍必需。

前轮财报复核保留了 8 份 PDF 哈希比对和 67 项原值在指定页出现的检查；这不能替代会计含义审查。此前浏览器已检查桌面、窄屏、窗口切换、证据钻取与真实本地回答；本轮新增 HTTP 回归记录，不将旧截图写成 V5 新浏览器验收。

## 明确边界

不作直接买卖建议、确定性股价预测或收益承诺。无事件因果识别、全市场覆盖、完整历史修订库、持续更新通知或账号同步。早期年份可在财务趋势查看已收录数值，但不支持任意年份专项自然语言诊断。规则与词法校验无法保证任意语句的事实正确性；失败或缺失不以正常结论掩盖。

题目中的 60—180 秒视频为可选项，本包提供演示步骤和早期预览图，未制作视频。提交前请候选人实际查看本地产品与本说明，确认能解释设计、数据口径、AI 使用与上述局限。
