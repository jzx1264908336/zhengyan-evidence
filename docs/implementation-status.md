## 后续建议顺序

1. 配置真实模型服务，先用固定 20 问题集重复验证结构、数字与语义，再加入模型问题理解；不要只接一个聊天框就宣布 AI Native 完成。
2. 核实扶摇和 iFinD 的实际授权及数据展示许可，实现服务器适配器。优先补同一时点估值、复权日线、交易日历与基准。
3. 补齐真实财务与事件更正样本，验证数据修订如何改变指标和解释。
4. 将最终源码放到评审可访问的仓库，完成干净环境复现，录制 60—180 秒视频；重新检查提交材料与当前版本一致后再提交。

不能将本版本直接描述为完成真实 LLM 全链路或实时市场诊断。提交前保留事实边界，比用模拟响应掩盖缺项更重要。
