最新本地推理增量见 [本地模型验收](local-model-verification.md) 和 [真实20题结果](local-model-results.json)。已实际使用 Qwen3.5 9B，不把 OpenAI 额度失败、mock 契约或规则输出当作其真实生成结果。逐条语义检查仍发现部分不充分回答，已在报告中保留。

## 实际使用

使用 Codex 进行需求拆解、公开来源检索、数据核验脚本、TypeScript 计算/规则、React 页面、接口、自动化测试和文档编写；使用 Sites 技能进行脚手架与托管准备，PDF 技能工作流进行报告提取与选页渲染核验。

初版运行时 LLM 适配使用可配置的 HTTPS Chat Completions 契约，当时没有用户提供的服务凭证，未进行真实模型调用。2026-11-05 更新 OpenAI 配置后的实际验证见文末；模拟测试不作为真实模型能力证据。

## 已发现并修正的错误或不合理结果

1. Windows 上 starter 的 Node 复制过程遇到 EIO。改为保留 Site 身份、用 Python 复制同一 starter 其余文件，再执行原配置工具，未自行替换托管集成。
2. 初版 TypeScript 编译目标过低，不能接受 BigInt；已提高到 ES2022。首次增量检查残留错误，通过禁用增量完整检查确认修复。
3. API 测试直接运行 TypeScript 时，扩展名缺失导致加载失败；修正测试依赖的导入路径，完整测试重新通过。
4. 检索财报时发现母公司现金流与合并现金流容易混淆：主产品使用合并经营现金流，并配合合并净利润，归母净利润单列。
5. 现金流增长容易被解释为终端需求改善；依据财报第 3 页说明，改为结构化展示财务公司原因和待核验边界。
6. 同行五粮液报告披露收入确认核算调整，因此不机械纳入默认中位数。
7. 初版风险维度没有独立结论，已补充研究结论的证据边界卡片，不把资料不足写成公司已发生问题。

## 验证方式

- 原始 PDF 在独立研究目录保存并计算 SHA-256，不打包全文进入公开工程。
- 59 项原值逐一断言存在于引用页；关键表格与原因说明另经选页渲染检查。
- 季度加总采用独立 BigInt 分计算，核对年度总值。
- 规则、模型输出与 API 测试覆盖未知、非法引用、未经计算的数字、交易诱导、超时/错误响应等情况。
- 模型结构校验不等同于语义正确；真实模型反复运行、语义对照审查和提示注入的真实运行测试仍待凭证配置。

不能声称候选人已亲自修正或审核所有内容。本记录描述本次 AI 开发过程中实际发生的修正，候选人仍需审核提交材料与真实产品边界。
