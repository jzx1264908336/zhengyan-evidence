## 可选模型配置

复制 `.env.example` 为本地私有 `.env`（如当前运行模式不加载该文件，可设置进程环境变量后启动）。生产环境通过托管平台的环境变量功能设置；不得提交真实值。

| 变量 | 用途 |
|---|---|
| MODEL_API_KEY | 服务端模型密钥；未设置时诚实降级 |
| MODEL_ENDPOINT | HTTPS Chat Completions 地址，默认 DeepSeek 官方服务 |
| MODEL_NAME | 实际获授权模型名；默认值须按账号与服务文档核验 |

不同模型服务的字段兼容性需要真实调用验证。AI 输入仅包含当前公司、问题、已核验事实、相关指标与摘要材料。密钥不进入浏览器或模型提示词。

生产公开调用保护包括同源检查、输入大小限制、服务器快照校验、25 秒模型超时与每个 isolate 的最佳努力频次限制。该限制不是分布式全局账单保证；正式开放付费模型前应配置平台限流与预算。

## 产品取舍

- 主标的只做一家；同行用于比较，不伪装为全市场产品。
- 公司类型为非金融，但合并财务公司；现金流需有专门口径提示。
- 关键案例：2026 前三季度合并经营现金流显著增长，但销售回款增幅不同；公司原因解释涉及财务公司，不能直接推断酒类现金回收同幅改善。
- 年度、单季、累计期分开，TTM 由程序计算。
- 五粮液收入确认核算调整默认影响同行比较可比性，允许用户改变样本，但始终保留说明。
- 支持 PE TTM、PB、同行年度静态 PE、区间价格表现及最大回撤；保留供应商复权和报告期滞后的边界。
- 研究清单仅存当前浏览器，无账号同步；支持研究摘录导出。

## AI、规则与数据的分工

- **确定性计算**：单位转换、同比、TTM、毛利率、现金流比值、同行中位数、回撤函数和原始依赖。
- **已核验规则**：首版关键词任务路由、结构化事实、反证与信息缺口组织。无模型时只展示这部分。
- **可选 LLM**：在证据包中组织解释，输出结构化引用。所有数字使用指标占位符，由程序填入；引用和边界不通过则降级。
- **人工核验**：财报页码、字段含义、独立复算与固定案例语义审查。自动引用校验无法证明每句话的语义正确。

自由问题的理解目前以有限规则路由为主，不能理解任意金融问题；不同年份或问题细节未必获得专项答案，页面始终显示所用期次。模型服务配置后也需补充真实意图理解与语义评测，再提升这一部分。

## 数据与复现

原始来源包括交易所、巨潮承载的上市公司财报，山西汾酒文件为东方财富承载的公司原始报告。展示原文链接、PDF 页序、披露日期、获取日期和 SHA-256。只纳入事实性数值与自主转述，公开工程不包含整份原始 PDF。

数据核验脚本 `scripts/import-filings.py` 使用 pypdf 对每项原值所在页进行断言。它验证数值出现与定位，不替代会计字段语义核验。可将公开报告下载到独立研究目录并运行：

```powershell
python scripts/download-filings.py work/filings
python scripts/import-filings.py work/filings
```

需要 Python 与 pypdf。重新导入后必须核对数据版本、SHA、日期和全部受影响结论。数值快照在 `lib/research/snapshot.json`；完整字段字典见 [数据说明](docs/data-dictionary.md)。

## 已知边界和未做事项

真实模型调用与语义评测未执行；指定金融接口未接入；无因果识别、持续监控通知、完整历史修订库、账号同步或全市场覆盖。更正比较仅覆盖五粮液同一季度报告的两份已核验版本。构造测试只验证异常与计算，不作为真实公司事实展示。

不输出确定性股价预测、直接交易指令或收益承诺。产品服务于证据研究，不构成投资建议。
