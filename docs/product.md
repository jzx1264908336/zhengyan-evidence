# 产品设计

目标用户：希望理解公司经营变化、愿意核验财报的个人研究者。

核心任务：提出问题，理解结论，查看支持和反对证据，核验计算与原文，把未知保存为下一步研究问题。

信息架构：诊断总览、财务与趋势、行情与估值、同行比较、更正与版本、事件与风险、证据来源、研究清单。右侧研究导航展示七维范围；手机采用顶部横向导航。

关键设计：没有综合推荐分；正面事实不直接升级为买入建议；冲突与未知具有独立入口；每个数值可以钻取到原始输入；原文是公告 PDF 的页级链接。研究清单在本地浏览器保存，刷新可恢复，导出为自主整理的 Markdown 摘录。

AI 解读被拆成可选层；无凭证时仍可操作已核验数据与规则，并明确显示不是实时 AI。相较通用聊天工具，重点是可复核的证据对象和正确的时间/合并范围。

金融案例：2026 前三季度现金流增长不等于酒类销售回款同幅改善，用户可查看两个同比指标及公司关于财务公司影响的说明。由此继续核验分部现金流，符合从结论继续研究的目标。

产品不宣称推断已被证实，也不宣称覆盖所有公开公告。行情和估值通过公开固定快照补充；合理性与因果缺少证据时仍保留未知。当前实现不是完整的任意公司 Agent，未配置模型时自由问题仅通过规则映射到有限任务。
