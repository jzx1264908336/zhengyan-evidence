# 约 89 秒实际演示视频（V8）

成果包内 `demo/证研-V8-实际操作演示.mp4`，H.264 MP4，1280×810，12 fps 编码，中文字幕、无配音。实际编码时长约 89.08 秒，满足题目可选 60—180 秒范围。

本视频来自本地产品标签页的实际画面采集，采集约 2 fps，保留真实 AI 输出、网络查询、自动核验和原文钻取。以 124 个实际画面编码，静止等待片段最长保留 3 秒，字幕为后期说明；不是从设计稿合成的假操作，也不是对全桌面的连续录制。不包含密钥、账号页或终端内容。

演示顺序：

| 约略时间 | 实际内容 |
|---|---|
| 0—6 秒 | 本地 Ollama 真实证据解读，保留主业/财务公司边界 |
| 6—16 秒 | 点击指标，查看同比公式与原始财报数据 |
| 16—43 秒 | 发起 iFinD MCP 查询，查看真实年度返回与单位/期次提示 |
| 43—59 秒 | 单位归一化、精确十进制舍入区间，以及 MRQ 期次未决的自动判定 |
| 59—67 秒 | 展开核验依据，钻取年度财报原值与第 6 页来源 |
| 67—81 秒 | 独立调用扶摇，核验 23 项财务值一致 |
| 81—89 秒 | 展示结果与本地版本、公开预览、非投资建议边界 |

字幕与画面转换时间可能有少量采样偏差。前段 AI 请求在画面采集前已触发，开头展示实际生成结果；视频不把等待或截取编辑描述为模型即时完成。

视频已完成全片解码检查，抽查约 4、46、61、82 秒的画面，核对中文字幕、真实结果和未决状态；文件约 1 MB，随源码附件一并提交。技术记录见 `demo-video-metadata.json`。
